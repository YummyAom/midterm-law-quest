# 🕹️ Cyber Law Midterm Arcade 🏛️

> **"ลุยด่านข้อสอบกฎหมายดิจิทัลสุดมันส์ในสไตล์ Retro Arcade 80s!"**  
> เว็บแอปพลิเคชันควิซตอบคำถามเตรียมสอบมิดเทอมกฎหมายดิจิทัล (Digital Law & Cybersecurity Law) ที่มาพร้อมกับเอฟเฟกต์สุดเร้าใจ ระบบ WANTED LEVEL และเสียงเพลงสไตล์ตู้เกมย้อนยุค

## 🚀 ฟีเจอร์เด่นของระบบ (Features)
- **👾 Retro & Cyberpunk UI/UX:** ดีไซน์หน้าเว็บด้วยสไตล์จอกล่อง CRT, สีสันนีออนสุดจี๊ด (Neon Colors) และเอฟเฟกต์ไฟไซเรนตำรวจ
- **🚓 Wanted Level System:** ระดับความต้องการของตำรวจที่จะเพิ่มขึ้นเรื่อยๆ เมื่อคะแนนคุณสูงขึ้น! (ระวังเจอตำรวจแอบมองที่มุมจอ และเสียงหวอระดับสูงสุด!)
- **📝 Real Explanations Included:** เฉลยละเอียดพร้อมคำอธิบายหลักกฎหมายจริงครบถ้วนทั้ง 49 ข้อ ทั้ง พ.ร.บ.คอมพิวเตอร์, พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์, NDA และจริยธรรมคอมพิวเตอร์
- **🎵 Retro Audio Effects:** เสียงดนตรีประกอบและ Sound Effects เวลาตอบถูก/ตอบผิด หรือเลเวลอัป
- **📱 Responsive Design:** รองรับทั้งการเปิดเล่นบนมือถือ แท็บเล็ต และคอมพิวเตอร์

---

## 📚 หมวดหมู่เนื้อหาที่ครอบคลุม (Question Categories)
ควิซทั้งหมด **49 ข้อ** ครอบคลุมกฎหมายหลักที่ใช้สอบมิดเทอม:
1. **พ.ร.บ. ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ & สัญญาไม่เปิดเผยข้อมูล (NDA)** (ข้อ 1 - 14)
2. **จริยธรรมทางคอมพิวเตอร์ (Computer Ethics & PAPA)** (ข้อ 15 - 24)
3. **หลักความมั่นคงปลอดภัยไซเบอร์ (Cybersecurity & Risk Management)** (ข้อ 25 - 38)
4. **พ.ร.บ. ว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์** (ข้อ 39 - 49)

## 💻 วิธีการรันบนเครื่องของคุณ (How to Run)
เนื่องจากตัวเว็บใช้เทคโนโลยี HTML5 + Vanilla JS และดึงข้อมูลคำถามผ่านไฟล์ระบบ คุณสามารถรันเว็บเซิร์ฟเวอร์จำลองในเครื่องได้ง่ายๆ:

1. **เปิด Terminal** ในโฟลเดอร์ของโปรเจกต์นี้
2. **รันคำสั่งเปิดเซิร์ฟเวอร์ด้วย Python:**
   ```bash
   python3 -m http.server 8000
   ```
3. **เปิดบราวเซอร์** แล้วเข้าไปที่ลิงก์:
   ```
   http://localhost:8000
   ```
